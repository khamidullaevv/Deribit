✨ РЕАЛИЗОВАННЫЕ ТРЕБОВАНИЯ
═══════════════════════════════════════════════════════════════════════════

1️⃣ DERIBIT КЛИЕНТ
  ✅ Получение цен BTC/USD и ETH/USD каждую минуту
  ✅ aiohttp для асинхронных HTTP запросов
  ✅ Сохранение в PostgreSQL (ticker, price, timestamp)
  ✅ Celery + Celery Beat для периодического выполнения
  ✅ Обработка ошибок и таймауты

2️⃣ REST API (Django REST Framework)
  ✅ GET /api/prices/all/?ticker=btc_usd
     → Все сохраненные данные по валюте с пагинацией
  
  ✅ GET /api/prices/latest/?ticker=btc_usd
     → Последняя цена валюты
  
  ✅ GET /api/prices/range/?ticker=btc_usd&start_date=...&end_date=...
     → Цены с фильтрацией по дате
  
  ✅ Обязательный query-параметр: ticker
  ✅ Валидация входных параметров
  ✅ Типизированные ответы через serializers

3️⃣ БАЗА ДАННЫХ
  ✅ PostgreSQL
  ✅ Django ORM (модель Price)
  ✅ Индексы по ticker и timestamp
  ✅ Миграции через Django migrations

4️⃣ АРХИТЕКТУРА
  ✅ Чистая архитектура
  ✅ Service Layer Pattern
  ✅ Dependency Injection
  ✅ Без глобальных переменных
  ✅ Активное использование ООП
  ✅ Celery задачи без бизнес-логики
  ✅ Отдельный класс для Deribit клиента

5️⃣ DOCKER (ОПЦИОНАЛЬНО)
  ✅ Два + контейнера:
    • Django + Gunicorn
    • PostgreSQL
    • Redis
    • Celery Worker
    • Celery Beat
  ✅ docker-compose.yml
  ✅ Переменные окружения через .env

6️⃣ ТЕСТЫ (ЖЕЛАТЕЛЬНО)
  ✅ pytest + Django TestCase
  ✅ Unit тесты для сервисного слоя
  ✅ Integration тесты для API
  ✅ Mock тесты для зависимостей
  ✅ Async тесты для DeribitAPIClient

7️⃣ README.MD (ОБЯЗАТЕЛЬНО)
  ✅ Краткое описание проекта
  ✅ Стек технологий
